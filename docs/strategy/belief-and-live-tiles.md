# 核心策略 1：算活张与牌堆 Belief

ZiMortal 的第一条核心策略不是简单记牌，而是持续估计：**你要胡的牌还在不在牌堆里，以及至少还可能有几张。**

## 1. 四张守恒

每一种牌共4张。

对目标牌 X：

> 牌堆中的 X = 4 - 已确定不在牌堆中的 X

需要同时考虑：

- 自己手中的 X
- 已公开的 X
- 吃、碰、偎、臭偎、跑、提锁定的 X
- 对手暗手中 X 的上下界

实战上更重要的是求上下界，而不是强求一个精确值。

## 2. 强制动作提供强信息

### 摸到 X 但没有偎

偎是强制动作。

若某玩家摸到 X 却没有偎，则可推出：

- 在摸牌前，该玩家手中的 X 最多1张。

这是非常重要的负信息。

### 吃 X 且完成下比

由于吃牌后相关牌必须全部下比，成功完成吃牌和下比后，可以强烈约束该玩家手中剩余 X 的数量。

尤其是“吃了但没有额外下比”本身就是手牌信息。

### 偎 / 臭偎 X

可确定有3张 X 已锁定。

### 碰 X

可确定有3张 X 已锁定，但由于碰不是强制动作，“没碰”不能推出没有一对 X。

### 跑 / 提 X

4张 X 全部锁定，X 对其他玩家而言成为死张。

## 3. 负信息的可信度

大致可按以下顺序理解：

> 提 / 跑 > 偎 / 臭偎 > 吃 + 下比 > 普通公开牌 > 没碰

其中：

- “没偎”是强信息，因为偎强制。
- “没碰”是弱信息，因为碰可以主动放弃。

## 4. 活张四档

### 硬活

通过约束可证明牌堆中至少还有1张。

### 大概率活

无法严格证明，但结合对手行为，目标牌大概率仍在牌堆。

### 虚活

表面上还有未出现的目标牌，但这些牌完全可能全部藏在对手手中。

### 死张

4张目标牌的位置都已确定，牌堆中为0张。

## 5. 训练目标

ZiMortal 的 belief 模型可针对20种牌分别预测：

- P(牌堆中0张)
- P(牌堆中1张)
- P(牌堆中2张)
- P(牌堆中3张)
- P(牌堆中4张)

也可以直接学习：

- P(牌堆中至少还有1张 X)
- E[牌堆中 X 的剩余张数]

训练时，模拟器掌握完整隐藏状态，但模型只能看到真实玩家可见的信息。
