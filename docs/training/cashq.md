# 第八轮：无人工牌谱的模拟现金Q训练

本轮只使用规则引擎生成的合法对局和Observation，未导入人工牌谱。不改变游戏规则。

## 数据与标签

从第五轮、十万级及第六轮模型，以及旧启发式教师的轨迹采样。每个独立开局最多取一个搜索根状态，按早（动作1～15）、中（16～40）、晚（41之后）优先轮换；某阶段缺少可选动作或历史一致采样失败时，尝试其他阶段并记录实际分布。动作步号包含过牌与强制动作，不等于摸牌轮数。

计划训练256根、验证64根，每个候选动作16次终局rollout。训练种子从38000开始，验证从39800开始；按实际接受情况推进。生成分片可恢复，每个分片记录校验值，跨拆分去重复；不能将同一根的候选动作、终局rollout或epoch重复计为独立局面。

搜索老师只接收Observation，均匀采样满足完整公开历史的隐藏世界；拒绝采不到合法粒子的根，绝不使用真实对手暗手或未来牌堆补齐。所有候选动作共用相同粒子，记录现金Q均值、各动作标准误及相对父模型动作的配对标准误。后续策略冻结为第五轮huxi、三家相同；这不是最优EV，也没有按对手行为概率校准隐藏世界分布。

后续对局的可选动作按批次推理，强制动作直接用引擎执行。串行/批量回归使用相同粒子、确定性策略，验证终局收益与配对误差完全一致。批量只合并独立Observation，不把完整隐藏状态送入网络。

## 模型与训练

冻结第五轮55×20 ResNet编码器和原策略/value头，在128维latent、候选动作编码、候选牌对应的可见通道摘要、原策略分数上，训练三个现金Q回归头。每个头为MLP 256→64→1。Q单位为净收益/100，输出真实金额时乘100。

采用bootstrap成员采样、Huber现金回归、相对基线动作的收益差回归，以及MC软排序辅助损失；标签不裁剪。高方差配对标签降低权重。冻结父模型保证新增训练不会改坏原有policy，而不是保证Q头变强。

推理默认使用父模型动作；只有预测候选收益提升减去2倍成员间分歧后，仍超过现金阈值，才采用Q动作。该分歧是启发式不确定性指标，不是校准的统计置信区间。

## 晋级与对局审查

阈值5/10/20元仅在开发种子41000～41029对冻结基线及教师选择；最终评估种子43000开始，不用于标签或训练选择。对冻结第五轮、旧教师、十万级历史模型、随机对手分别评估，轮换三个座位、按牌堆种子聚合收益做配对bootstrap。

预设晋级条件：对冻结基线、教师、历史模型的收益差95%区间下界均为正；随机对手结果另报。没有通过时保留第五轮冠军，实验权重保存供研究。冠军登记在本机checkpoints/champion.json，旧模型不覆盖。

每epoch原子保存完整训练状态和数据、父模型、最佳权重校验值。WSL运行独立systemd用户服务，8GiB内存/1GiB swap上限，6核CPU配额，日志在logs目录。

```bash
scripts/train-cashq-wsl.sh build --roots 256 --valid-roots 64 --rollouts 16
scripts/train-cashq-wsl.sh audit --report docs/training/cashq-data-audit.json
scripts/train-cashq-wsl.sh train --device cuda --epochs 40 --selection cash_rmse
scripts/train-cashq-wsl.sh evaluate --report docs/training/cashq-comparison.json --eval-seeds 100
```

各命令独立，须确认前一服务成功再运行下一步。训练中断时加--continue-training；epochs为总目标轮数。生成恢复直接重复build，原配置必须一致。

## 剩余差距

依然缺少长期自博弈更新、按对手策略加权的belief、足够覆盖罕见名堂的回报标签，以及更高速的规则模拟。冻结老师可能限制最终策略上限。单轮Q拟合、局部收益改善或对随机更强都不能证明高强度；必须报告实际独立收益和未通过的晋级条件。

## 实际数据与训练结果（2026-10-08）

生成320个不同输入、不同开局的搜索根：训练256（早148／中67／晚41），验证64（早31／中19／晚14）。训练1,547个候选动作、24,752次终局推演；验证431个候选动作、6,896次推演，总计31,648次。旧107k数据只通过父模型预训练间接使用，本轮不是新增十万级搜索局面。历史一致采样失败50次（早2／中23／晚25），均拒绝该候选根或回退其他阶段，没有读取真实隐藏牌补齐。

[数据审计](cashq-data-audit.json)重建16个根的公开输入及合法动作；训练／验证各首个根的全部现金均值、标准误和配对标准误按原种子重新推演，逐项完全一致。根轨迹检查四张守恒及完整终局重放，跨训练／验证重复为0。

完成两份40epoch CUDA训练。均冻结第五轮编码器及旧policy/value，只更新三个Q头；实际使用RTX5080、PyTorch2.7.1+cu128。首份约7.21秒、峰值RSS1.88GiB，Torch峰值张量显存约29.6MiB。生成和评测的主要成本在CPU规则模拟，不在GPU训练。

| 权重选择 | 最佳epoch | 验证现金RMSE | 无门控MC动作损失 | 父模型MC动作损失 |
| --- | ---: | ---: | ---: | ---: |
| 数值拟合：RMSE + 0.1×动作损失 | 3 | 21.96 | 12.93 | 12.63 |
| 动作排序：动作损失 + 0.01×RMSE | 38 | 23.65 | 11.98 | 12.63 |

金额为结算单位。MC动作损失是样本推演最优动作与所选动作的平均Q差；16次推演存在噪声，不能当作真实最优策略损失。数值拟合改善不等于排序改善，第二份因此改用动作损失为主的验证选择。bootstrap三个成员使用同一网络latent，分歧仍未校准。

首份在41000～41029选择阈值，43000～43099四类对手各300场、父模型与候选各测一次。收益与父模型完全一致，未晋级：对第五轮0.00、教师−3.35、十万级历史模型+4.48、随机+17.25；配对收益差均0。这不是能力提升。

第二份采用全新开发45000～45029与留出47000～47099，避免重复利用首份留出对局。复现时首份须指定`--selection cash_rmse`，第二份命令为：

```bash
scripts/train-cashq-wsl.sh train --device cuda --epochs 40 --selection policy_regret --output checkpoints/cashq-regret.pt --report docs/training/cashq-regret-training.json
scripts/train-cashq-wsl.sh evaluate --output checkpoints/cashq-regret.pt --report docs/training/cashq-regret-comparison.json --dev-start 45000 --eval-start 47000 --eval-seeds 100
```

原始无门控训练权重与门控部署权重分别保存，评测不覆盖训练checkpoint，保证恢复校验可继续使用。恢复时也校验权重选择标准。网页`cashq`使用第二份排序权重，`cashq_rmse`保留首份数值拟合对照；逐动作金额全部由Observation预测。

## 独立实战与复盘结论

[排序对照评测](cashq-regret-comparison.json)选择20元阈值，留出每类对手100种子×3座位=300场；基线及候选共2,400场。候选1,200场共有10,694次可选决策，实际换动作0次，因此所有收益差与95%配对区间均为0，未晋级。第五轮`huxi`继续作为冠军，不能将本轮称为棋力提升。

| 对手 | 基线／候选平均收益 | 候选胜场 | 实际换动作／可选决策 |
| --- | ---: | ---: | ---: |
| 第五轮冻结模型 | 0.00 | 87/300 | 0/2600 |
| 旧启发式教师 | −0.62 | 67/300 | 0/2513 |
| 十万级历史模型 | +4.40 | 96/300 | 0/2659 |
| 随机 | +20.45 | 123/300 | 0/2922 |

两次评测总计4,800场留出对局，另有1,080场开发对局；不是独立5,880个牌堆种子。预设门控保护了旧策略，也完全挡住了这次实验的行为变化；降低阈值没有稳定的开发收益依据，不能仅为“让模型动起来”修改正式晋级标准。罕见收益与较小动作优势仍需更精确标签。

[100场审查](cashq-game-review.json)使用44500～44599，共5,498步，78场有人胡；全部四张守恒及完整重放通过，12个策略分歧保留人工研究。混合对手评测发现两个已有父策略过胡：seed47073玩家二第72步（对十万级模型），seed47086玩家二第41步（对随机）；候选与父模型均如此，未发生非法动作。混合对手轨迹与网页三家同策略轨迹不同，不应沿用网页同种子的步号。

另对[seed44501第5步](http://127.0.0.1:8765/?seed=44501&dealer=2&policy=cashq)玩家三吃壹的分歧做[64粒子现金复算](cashq-case-study.json)，仅供审查、不加入训练：

| 动作 | 网络现金预测 | 64次MC均值 | 相对“一一壹”配对标准误 |
| --- | ---: | ---: | ---: |
| 吃一一壹（父策略／当前采用） | +3.32 | −7.97 | 0 |
| 吃壹贰叁 | −3.14 | −3.13 | 6.17 |
| 过 | −1.17 | −12.81 | 7.31 |

网络与MC对两种吃法的排序相反，但4.84元MC优势小于配对误差，不能据此认定最优吃法。这说明还需要对高分歧的吃法和拆高胡息组合主动增加推演，而不是继续用同一批低精度标签加深网络。

最终验证：CPU环境205通过、1项CUDA测试跳过；实际CUDA环境206通过；Ruff及`git diff --check`通过。浏览器1440px／390px下逐动作表与合法候选数量一致，三家显示、首尾导航正常，无页面横向溢出及JavaScript错误。六个独立生成／审计／训练／评测服务均成功结束，无OOM。本地复盘服务已重启加载最终版本。

下一轮优先：对网络／搜索／父策略分歧最大的合法状态增加共同粒子推演，自适应缩小动作差误差；改善晚局隐藏世界采样，随后将冻结后续策略扩展为混合对手池及滚动自博弈。仍缺可信收益优势、罕见名堂覆盖和对手行为加权belief；没有人工牌谱不阻止继续做这些工作。
