# 十万级数据训练（第四次迭代）

## 数据与复现

```bash
.venv/bin/python -m zimortal.training.scale build --workers 4
.venv/bin/python -m zimortal.training.scale audit
.venv/bin/python -m zimortal.training.scale train --epochs 10
.venv/bin/python -m zimortal.training.scale benchmark
.venv/bin/python -m zimortal.training.review --checkpoint checkpoints/scale100k-resnet.pt --start 18000 --games 100 --output docs/training/scale100k-review.json
```

本机 PyTorch 2.14.1+cpu、NumPy 2.5.2；生成使用4个进程，训练使用2个 CPU 线程。
数据文件位于 `data/generated/scale100k/`，权重位于 `checkpoints/scale100k-resnet.pt`，二者按仓库约定不纳入 Git。指标、权重校验值和数据清单校验值保存在 `scale100k.json`。

生成119个数值 NPZ 分片，动作使用 ragged offsets，加载不使用 pickle；每片保留 seed 配置、样本数、SHA256。可重跑生成命令复用校验通过的分片。`generator.json` 固定编码器、教师和引擎源文件的校验值，源码改变后必须另建数据目录，不能静默复用旧标签。训练先核对哈希、样本数与标签索引范围。

- 训练临胡题：50000条，0～3次扰动各12500条。扰动次数仍不是精确向听数。
- 训练完整随机对局：2048场，产生57034条非强制决策。
- 原始训练总数107034，按“编码状态＋完整候选动作张量”去重后实际训练 **107031条不同输入**。
- 验证：2000条临胡题＋96场随机对局产生2675条决策，合计4675；去重复并排除与训练相同输入后保留 **4674条**。
- 训练 puzzle namespace400～449，game namespace500～563；验证 puzzle800～801，game850～852。namespace对应100000个 seed 的块，本次每块仅使用1000道题或32场对局，互不重叠。
- 只从 Observation 生成输入和教师标签，完整暗手仅属于模拟器。这里是监督数据扩容，没有将107031条样本冒称为107031场对局，也没有将重复训练10个epoch计为新增数据。

抽查24场源对局、648条存储决策、1715步，以及50道临胡题：重新生成并逐项比对输入／候选／标签，检查四张守恒和完整重放；结果见 `scale100k-data-audit.json`。这是抽查，不能宣称人工审查了全部数据。

## 训练

从第二轮 ResNet 继续，因为此批 value 标签仍是即时胡牌／自摸听牌 readiness，与第二轮目标一致；第三轮终局收益 value 不混入此次监督训练。

网络仍为45×20输入、两层1D residual block、policy／value／听牌辅助头。AdamW lr3e-4、weight decay1e-4，batch128、梯度范数上限5；policy CE＋0.2 readiness BCE＋0.1听牌 BCE。训练10个epoch，共1070310次样本呈现、8370次优化更新。依据独立验证 policy CE 最低选择权重，本次选中第10个epoch。

在同一4674条验证输入上，第二轮模型教师动作一致率71.87%、CE0.88379；训练后84.49%、CE0.50667。教师一致率不是胡牌率，也不是精确向听能力或棋力。权重和完整各epoch日志见 `scale100k.json`。

## 新种子评估与目标差距

种子16000～16049，每种子轮换模型三个座位、庄家seed%3，共150场对随机对手：

| 策略 | 胜场 | 胜率 | 平均结算收益 |
| --- | ---: | ---: | ---: |
| 第二轮 ResNet | 33 | 22.00% | 9.53 |
| 第三轮 ResNet | 28 | 18.67% | 7.93 |
| 十万级 ResNet | 41 | 27.33% | 19.30 |
| 启发式教师 | 69 | 46.00% | 16.40 |

种子17000～17019，对教师共60场：第二轮8胜，第三轮7胜，十万级模型8胜；十万级平均结算-19.50，第二轮-18.00。模型仍没有证明能超过教师；对随机对手的高平均收益也不足以证明长期收益更优。按种子轮换的三个座位相关，金额结果还会受少数高番对局影响，不作显著性或人类棋力声明。

十万级评估的210场无非法动作、无漏掉已提供的胡动作。另以种子18000～18099运行100场三个座位均使用新模型的审查对局，共6169步、67场有人胡，守恒与重放通过。此67/100是三人模型对局的有人胡比例，不能与上述单模型对随机的41/150胜率混用。
