# 同一状态下的完整路线现金比较

入口 `zimortal.training.routeq`。本版保留完成5,000局辅助训练的
`trajectory_v4` ResNet、强父 policy/value 和门子权重，新增 `RouteQNet`：

```
可见55×20特征 → 冻结ResNet → 状态128维
             → 可训练门子MLP → 每个候选组64维
完整方案的七组计数 + 用牌／缺牌／活张界／胡息界／名堂潜力
             → 方案编码器128维
状态 + 方案 → route V
状态 + 方案 + 合法动作编码 → action-conditioned cash Q
```

这里的门子由完整组模板在当前手牌中的局部覆盖表示，尚未覆盖所有人类命名的
两张组合；同一张牌可出现在多个备选门子中，进入一个完整方案后不得重复占用。
二贰的价值不是固定常量，输入保留另一张贰参与壹贰叁或贰柒拾的方案差异、
大小／红牌数量和可见历史。混搭成组本身按规则算0胡息，不凭经验添加胡息。

## 候选与标签

候选只依赖 Observation。组合解码固定公开组与手中坎，约束七组、四张上限、
有跑提才带将。除学习的非空组先验外，近手牌／胡息／大小／红牌多种可见提案
用于扩大候选多样性；合法吃及全部下比、碰的具体组也参与固定条件提案，
避免所有候选在吃碰后立即失效。提案经验权重不作为现金价值标签。

每个根保存多个完整方案，与每个合法第一动作组成二维表。HistorySampler
按完整公开历史重放筛选隐藏牌粒子；所有表项共用同一组粒子，随后执行：

- 首步执行表项中的合法动作。
- 原玩家采用冻结父logits加有界、可见的路线进展偏好；对手使用冻结父策略。
- 路线失效时回到父策略，不把该玩家的其他胡牌路线判死。
- 后续胡／过沿用父策略；根上胡／过本身仍分别展开。
- PASS产生不同公开信息集时，各自按当时Observation选择，不读取终局现金选动作。

现金来自真实终局payments/100。标签是 **Q(动作，明确的路线跟随策略)**，
不是该路线的最优EV，也不是承诺一定按目标七组胡牌。当前仍未展开固定坎／公开
三张组的升级替代路线；被迫升级后可回退。胡息、名堂潜力是条件界或结构特征，
不是精确实现概率。隐藏牌、终局组及未来现金仅保存在标签／审查证据中。

学习均值现金、同一根同一动作下的配对路线收益差；权重使用共同粒子的差值标准误，
设噪声下限，不把观测零方差解释为严格确定。各根总权重相同。
route V标签是父策略首步动作分布下的现金均值，不能用每粒子的oracle max。

## 验证与运行

训练根、开发根及选型后的独立检验根使用分开的完整牌局和粒子种子。
失败整根排除，保存失败Observation和原因，不赋流局零值。每个有效粒子保存
世界、完整分支后缀、终局结算及哈希，并用标准RuleEngine重放核对。
报告同根路线现金差误差、存在路线收益差的根数、路线改动作／回退次数，
以及独立检验的单次根动作＋路线切换收益。开发或小样本检验不替代完整代理牌力检验。

GPU进行编码与训练，CPU运行规则及历史采样；WSL后台上限8GiB内存、300%CPU，
保持2GiB磁盘保留线，源码和父权重冻结。最佳权重与匹配optimizer分别原子保存。
日志、每根数据、逐epoch指标只留本地。

```bash
ZIMORTAL_TRAINING_MODULE=zimortal.training.routeq \
  bash scripts/train-online-rl-wsl.sh \
  --directory data/generated/routeq-v1 \
  --roots 128 --dev-roots 32 --test-roots 16 \
  --particles 8 --test-particles 16 --epochs 24 --strength 8 --device cuda
```

`runtime.predict_route_q(model, observation)` 可查看每个动作／路线预测现金。
模型的普通 `forward` 保持父策略；本阶段不自动接管网页或自博弈动作。
下一阶段先审查路线收益差的泛化、稀有名堂覆盖和预测不确定性，之后做完整代理
独立现金评估再考虑接入强化学习。

## 人工审核后的下一阶段（2026-10-14）

[三题反馈与实施顺序](../strategy/reviews/routeq-human-review-20261014.md)指出，
终局七组方案不足以表达保留对子、替代进张、强制下比及首次跑胡的价值。
下一版先补升级事件与结构路径，优先无跑／一次升级，保留多次升级临界例外；
按真实来源计算胡息和流转，不把经验变成合法性禁令。随后比较动作及弃牌后果，
再生成独立共同粒子现金证据训练；本次仅记录与规划，尚未修改模型或启动新训练。

## v2升级路径与动作后果

候选现在展开公开碰／偎及手中坎升级分支，锁定其余组与四张容量，
首次升级必须带将；具体第四张来源仍是有条件事件，不是到达概率证明。
碰升级的胡息界固定为跑，偎／坎区分跑和提；原三张胡息不重复计入。
默认限制比现有结构多一个四张组。已有升级且锁定胡息已达15时不优先展开
进一步固定组升级；不足15时保留一个额外升级分支。强制动作始终由引擎执行。
升级及合法吃／下比各保留候选预算，空结果仍为unknown。

吃及全部下比、碰的路线预览包含接下来的合法弃牌，并保留起手双提免弃牌例外；
坎不可拆，弃牌进入公开库存上界。选取可继续目标的最佳可见弃牌进展，
后续实际行为仍为冻结父logits加有界偏好，并非最优两步搜索。
对子保护和替代门子主要由完整目标的互斥用牌表达，尚无校准的替代进张价值预测；
不会凭人工偏好增加现金奖励。原始分支保留升级事件、弃牌与全后缀重放。

架构维度保持兼容，使用全新种子和目录，不混用v1标签。
新增`--cash-games`与`--cash-start`在开发选型及独立根检验后执行完整牌局现金比较：
Q实验代理每次自己自由决策重新规划，对手冻结父策略，同种子轮换三个座位，
按种子聚合并保留全部重放。此代理不同于Q标签的冻结路线跟随策略；
小样本、单一对手现金比较不替代正式多对手晋级。
