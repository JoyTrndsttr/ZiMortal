# 两步 Branch Teacher 诊断

本轮仅实现并验证诊断工具，不启动PPO、5k数据集或蒸馏，不替换冠军。

## 实现与口径

入口 `zimortal.training.branch_teacher.evaluate_two_step_branches` 只接受Observation与冻结模型。复用HistorySampler按公开历史完整重放采样；每个粒子用于全部第一动作和同一后续公开信息集的全部第二动作。所有后续玩家均使用同一冻结greedy策略，环境随机性由共同粒子的完整牌堆承担，没有按branch重抽随机动作。

第一步执行后，自动执行单一合法动作，包括强制偎／提／跑、摸牌及只有一种合法弃牌的情况；其他玩家自由选择使用冻结策略。只在原玩家拥有多个合法动作时展开第二步。终局第一步直接记录结算。每个第二动作独立克隆并推演至终局，记录原玩家真实payments现金；不除100、不改奖励。任一规则未定义或采样失败使整个root失败，不拿成功分支补零或重采样掩盖问题。

人工题的原始prefix补存至 `docs/strategy/reviews/human-review-v1.json`，从seed/dealer重放仅用于建立可见Observation。teacher不接收真实开局牌堆、对手手牌或网页frame。原始粒子哈希、逐分支收益、配置与性能profile只留本地 `data/generated/branch-teacher-v1/`，已有data/generated忽略规则覆盖；不提交逐粒子JSON。

## 动态第二步的边界

PASS之后，不同粒子可能有不同进张、公开动作和合法选项。因此按完整可见Observation哈希分组，不能把不同信息集的Q合并，再替每个隐藏世界选最优动作。仅当所有第一动作都到达各自固定的第二公开信息集时，才可以全粒子比较序列并形成root max-Q。当前动态root显式 unresolved，尚不生成“Q(a1)=max_a2”训练目标。对碰后固定弃牌等分支仍能使用全部共同粒子比较现金差。

统计输出包括mean、SE、相对观察均值最佳动作的paired差／SE／CI。间隔16→32→64→128（配置可至256），对计划查看次数、动作对及信息集进行Bonferroni分配。区间采用近似正态MC推断，不是分布无关的严格序贯认证，尤其离散稀有高收益和小样本时可能失准。包含零不判tie，零样本方差也不认证排序；unresolved不产出硬标签。进入蒸馏前还需独立复核及校准。

## 实验计划与验证

固定league-v4第二阶段开发候选为所有席位的continuation，用split-001、split-002、split-005及split-002第2／13步原状态，各128共同粒子。CPU/CUDA各2粒子split-001 smoke结果逐粒子现金与公开轨迹一致。单位速度以正式运行的wall time为准，采样含完整历史重放，profile用于细分瓶颈。



## 实验结果

五个不同诊断根都完成128个共同粒子；split-001另以seed8812做独立128粒子复核。两批的源码、模型及人工prefix校验值完全一致。第一次split-002提案上限2000在第0粒子失败，证据保留在主目录；整根在retry子目录以明确记录的100000上限重做，未改变采样器或分布。最终该根接受128粒子共用170406个提案，未发生未来规则失败。不使用失败根作标签。

### split-001，玩家3，第21步

完整第一动作只有碰一、过；碰一后10种合法弃牌全部展开。初批128：碰→五为8.3594（SE2.5560），碰→七为17.4219（SE1.9608），七减五为9.0625，paired SE2.8709。独立复核128：七18.0859、五5.5078，差12.5781，paired SE3.0839；没有为匹配人工意见改变规则、政策或结果。

七减五为 **10.8203，paired SE 2.1054，校正近似CI [2.1349,19.5057]**。该区间使用alpha0.01，Bonferroni覆盖10动作的45对比较及6次可能查看，仍是近似正态诊断，不是严格分布无关认证。指定比较可区分，独立复核也同方向。七减十的对应区间[-4.2952,9.2171]仍包含零；七与二也未稳定分开，因此整个弃牌排序仍是**insufficient evidence**，best_supported_action保持空，不把七变成硬性最优标签。七对五这个指定比较与整个排序必须分开理解。

初批在第一动作后直接沿模型选择第二步时，碰的平均8.3594、过7.7734，无法区分。换成碰后打七则17.4219，优于过后模型继续的指定比较也有正向近似证据；但过后的第二步可能还有更好的公开信息条件策略，不能把此数称为max-a2的Q(过)。

### split-005，玩家1，第22步

全部第一动作：吃九九玖＋下比柒捌玖；吃九玖玖；吃柒捌玖＋下比九九玖；过。三种吃法之后的所有合法弃牌均已推演。

| 第一方案 | 第二步沿冻结模型的参考现金 | SE | 观察均值最高的第二步序列及现金 |
| --- | ---: | ---: | --- |
| 吃九九玖＋比柒捌玖 | -7.227 | 3.270 | 打叁，-5.430 |
| 吃九玖玖 | -6.328 | 2.579 | 打七，0.586 |
| 吃柒捌玖＋比九九玖 | -7.227 | 3.270 | 打叁，-5.430 |
| 过 | -4.727 | 3.726 | 第二状态随粒子变化，不能跨信息集选max |

没有稳定的优胜序列。这张来牌形成的九玖玖不是“来小字吃一对大字”的板。初始本人13张大字；该吃法加进大玖后为14张，距18张仍较远。模型继续的九玖玖分支本人仅赢12/128，其中十八大1次；这只是该冻结策略下的样本事件，不是十八大精确概率，更不能排除更强后续规划的收益。没有证据强迫吃或过，也不据结果把人工弱倾向写成标签。

## 验证、结论与下一步

完整pytest **290 passed，1 skipped**；Ruff与git diff --check通过。Branch Teacher专项10项测试覆盖共同世界、强制推进、原玩家选择、吃碰弃牌、HU直接终局、整根规则／采样失败、配对统计、Observation-only、确定性、四张守恒及完整终局历史重放。CUDA环境专项10 passed；CPU/CUDA各2粒子原始现金轨迹完全一致。

这提供了具体证据：当前policy遗漏了“碰一之后打七”的现金价值，两步分支比单看碰概率更有用。**尚不能证明整个PPO平台期主要由long-horizon credit assignment造成**：另外两题未稳定支持人工倾向，采样后验只条件于公开历史合法性而未建模过去动作的策略似然，后续策略仍有限，状态表示也可能不足。

建议先优化历史一致采样与Observation编码、压缩证据格式，并明确PASS的公开信息条件策略及保守统计口径，再生成1000个高价值根；通过质量检查才扩到5k和蒸馏。当前root级max-Q均未认证，不输出硬／soft监督目标，不把unresolved根凑成数据集。本阶段到此停止：未启动下一轮PPO、数据集生产或branch_distill，也未更换冠军。

## 采样、编码和PASS处理优化（2026-10-12）

本轮按照用户最新要求完成基础优化，未生成1k～5k训练集，也未启动蒸馏或PPO。

采样保留原组合权重与随机序列：将每个DP状态的转移质量缓存为CDF，使用同一个随机ticket选取。
历史弃牌的非强制PASS只能来自碰或吃；非下家只能过碰，同一玩家连续两次过同一弃牌时依次为过碰、过吃。
据此从当前手牌逆推公开消耗偏移，廉价检查“必须有一对”或“至少存在基础吃搭”。
预过滤故意不检查坎、全部下比、出牌能力和其他玩家优先级，避免误删可行世界；最终仍须完整RuleEngine重放。
过滤不消耗随机数，拒绝提案仍计入原尝试次数。split-002的1000个固定提案仅92个通过必要检查，
减少了进入昂贵重放的无效提案，而非改变后验或降低质量要求。

可见编码分别缓存胡息／拆组通道、公开牌组通道、历史计数、完整可见特征和动作矩阵。
历史由多次扫描改为单次扫描，胡息递归只更新真正涉及的牌种。
缓存均有上限，完整特征按版本隔离，返回只读数组；不缓存网络输出，所以更换权重不会读到旧策略。

PASS保留完整公开信息集，不合并不同摸牌／对手动作的历史。现在每个a1另有固定策略参考Q：
在a2处仅用该信息集的Observation，让冻结模型选动作，随后从已经完整展开的分支取该动作现金。
选择发生在看到终局现金之前，同一信息集复用同一动作。所有a1仍用共同粒子，输出配对SE／CI。
这是 **Q(a1, frozen visible a2 policy)**，不是优化后的max-a2或可直接蒸馏的标签。
max-Q与参考诊断各分配根alpha的一半；区间仍为近似正态诊断，不作严格序贯认证。

例如split-002的PASS分支有114个信息集，103个仅一粒子；只有25个粒子落在重复出现的集合中。
冻结策略参考均值仍为碰33.672、过24.062，与上一阶段后处理一致；全局max-Q仍未收敛。
这揭示了真正缺口：必须在独立的搜索粒子上构建可见条件策略，再在独立评估粒子上比较，
不能在每个隐藏世界里各选现金最高的a2来“解决”稀疏信息集。

证据schema v2存为`{schema_version, information_sets, particles}`：Observation按hash保存一次，
每条分支通过information_set引用；组摘要不再重复整份Observation。
保留世界hash、a1/a2、终局cash/fan/winner和固定策略选择标记，能够还原旧证据的全部可见状态。
producer哈希新增整个belief包，避免采样源码变更未被配置冻结检查发现。
