# 平台期诊断与探索试验（2026-10-12）

## 下一轮方案

使用保留模型和对应best_optimizer起步。预算为2阶段×6代×4096局，共49152局，先验证探索调整，避免再无差别扩大同一训练配方。

- 训练采样温度2，PPO新旧动作概率使用同一温度；评估保持原始greedy策略，冻结对手仍用原始greedy动作。
- 价值损失系数0.5→0.1，父策略KL系数0.02→0.005，熵系数0.01→0.03，学习率3e-5→5e-5。
- 自博弈比例60%，冻结对手补充league-v1最佳、league-v3未晋级候选和online-rl-v2最佳；实验候选用作对手不等于晋级。
- 奖励仍为终局payments/100，无裁剪、无胡息／门子奖励塑形；人工倾向不写入合法性规则。
- 训练180000000、开发190000000、阶段检查200000000、最终留出210000000起，阶段步幅1000000；开发120种子，阶段检查600，最终1500。
- 数据、全部逐代和评估JSON放在 `data/generated/league-v4/`；不开启自动提交，仅代码及本总结纳入Git。

新增温度与损失配置保留旧默认值，旧命令行为不变。本轮是组合探索试验，不能从成功或失败单独判定某一个参数的因果效果。正式换模仍要求独立种子上的整体与对父模型收益证据；尚未得到新结果。之后优先复测吃碰之后的弃牌、早期保留门子与红胡计划，再按收益决定是否扩大训练。

## 完成结果与人工题复测

本轮已完成49152局、926887次决策，零模型晋级。第二阶段开发候选在600个阶段检查种子上的整体收益差为+1.5653，近似97.5%区间[0.0801,3.1130]；直接对父模型收益差+0.3556，区间[-1.6778,2.4028]，尚不足以换模。最后独立评估使用的是保留父模型，其相对huxi的+8.2737不能归为本轮训练提升。

用第二阶段开发候选重放同一份人工审核前缀，推理使用温度1，评估贪心选择；完整概率保留本地 `data/generated/league-v4/review-regression-after.json`。
