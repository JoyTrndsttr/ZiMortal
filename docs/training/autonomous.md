# 自动条件Q试验与真实现金强化学习

用户于2026-10-12授权每轮自行判断并执行下一步，恢复自动优化和训练。入口为
`zimortal.training.autonomous`，覆盖之前“只做诊断”的阶段性限制，不改变游戏规则或正式冠军。

## 每轮如何决定下一步

先从新牌局挖掘吃／比、碰／过、胡／过以及晚局状态；按模型不确定度和动作族优先级选题。
每副牌只留一个根，完整验证80张守恒与实际动作历史重放，不制造随机扰动手牌。
默认三轮分别增加8、16、32个搜索根，累计56根；每轮另有8个全新检验根。
每根32个独立、历史一致的共同粒子，完整展开a1与原玩家下一次非强制a2，后续固定父策略。

现金Q只用a2的可见特征与动作矩阵预测实际终局净现金/100。父ResNet冻结，训练三个Q头；
相同信息集的现金按粒子求平均，各根总损失权重相同，单样本状态使用非零保守损失权重。
这些是有噪声的辅助回归样本，**不是经认证的根标签，也不进行policy蒸馏**。
下一轮续用匹配的Q权重／优化器并累计搜索语料。

新牌局检验时，Q仅从可见a2选择动作，不看每个隐藏世界的现金；
选择后才从共同粒子的完整分支中读取收益，与冻结模型的a2配对。
a1固定为父策略选择，收益先按牌局聚合，再计算近似正态区间；三轮分享误差预算。
区间下界为正且非零方差时，试验Q用于下一轮挖掘行为，否则继续保留父行为并扩大关键状态覆盖。
此检验仅是小规模探索，不是正式晋级或严格全局认证；不把包含零判成tie。

条件Q试验后自动运行三阶段PPO。首阶段4×2048局，后两阶段各4×4096局，
共40960局；从`league-v2/stage-02/best-dev.pt`和匹配的`last.pt`最佳优化器继续。
60%自博弈，其余混合冻结父模型、scale100k、league-v3/v4、planning与近期快照。
探索温度1.5，value/entropy/anchor系数0.1/0.02/0.01，学习率3e-5；收益仍为终局payments/100。
每阶段开发80种子、晋级检查400种子，最后1000种子独立评估；不以训练损失声称变强。
满足既有联赛现金门槛才替换实验基准并加入对手池；不满足时累计当前训练权重／优化器继续下一阶段。
条件Q没有作为PPO初始化，未经验证的监督标签不会混入PPO。

## 资源、证据和恢复

CPU处理引擎／采样，CUDA更新Q与PPO。通过已有WSL启动器限制CPU300%、内存8G、交换1G。
原始Observation按信息集索引，全部分支证据gzip保存；逐文件哈希、父权重、优化器身份和producer源码冻结。
搜索／检验使用320000000／350000000起始种子，每轮间隔100000；PPO四类种子从400000000起，完全分离。
人工审核题不进入训练，规则未定义整局／整根排除并留下原因和已有证据。
每根写入仍保持2GiB空闲线，开始PPO前另留64MiB检查点预算；不通过时明确failed，不跳过保护。

曾因磁盘空间低于保留线而使旧证据测试失败。本次将v1/retry五份原始JSON无损gzip，
逐份核对解压SHA256后替换，内容仍完整保留；迁移记录在`raw-compression.json`，释放约212MiB。
旧后处理脚本已改读压缩文件。不是删除训练数据或降低保护阈值。

自动任务只保存本地逐轮／逐代指标，不自动commit。代码和重要实验结论再提交。
如果源码改动，必须在任务退出后开新版本；不得向现有生产目录混入不同源码。
支持同一冻结配置重跑：检查压缩证据哈希并复用合法根，从匹配的前轮Q优化器重新构建轮次链；
联赛自身支持按阶段恢复。损坏或缺少校验的证据报错，不静默接受。

验证：完整pytest **301 passed，1 skipped**，Ruff通过。CPU端到端smoke完成两轮、6搜索根与4检验根，
两次结果均未支持采用新Q，程序保留父行为。该smoke只有4粒子/根、2epoch，仅用于验证闭环和冻结编码器，
不作为模型强度证据。正式三轮任务的实际结果另写本地日志及后续重要总结。

启动命令：

```bash
ZIMORTAL_TRAINING_MODULE=zimortal.training.autonomous \
  scripts/train-online-rl-wsl.sh --directory data/generated/autonomous-v1
```

读状态先看`data/generated/autonomous-v1/progress.json`；进入PPO后再看`league/league-progress.json`
和其中stage_progress指向的文件。systemd状态为active/exited表示结束，不表示训练仍在运行。

距目标仍缺少证明条件搜索持续提高净收益的独立证据，以及足够稳定、可蒸馏的高价值根。
因此先自动完成小规模条件Q试验与真实PPO，依据现金收益决定后续优化；不直接声称千级根已经达标。
