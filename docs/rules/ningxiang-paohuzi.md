# 宁乡跑胡子规则

## 1. 基本规则

- 3人局，不属醒。
- 15胡起胡。
- 只有牌堆摸出的牌可以胡，别人打出的牌不能胡。
- 同一张牌多人可胡时，优先级：摸牌者 > 下家 > 上家。
- 达成胡牌条件后可以选择不胡，继续赌更大的胡息或名堂。
- 无海底。
- 一人胡牌后，另外两家分别支付相同金额，无放炮概念。
- “分锅”仅为玩家口头约定。

## 2. 胡息

| 牌型 | 小字 | 大字 |
|---|---:|---:|
| 碰 | 1胡 | 3胡 |
| 偎 / 坎 | 3胡 | 6胡 |
| 跑 | 6胡 | 9胡 |
| 提 | 9胡 | 12胡 |
| 一二三 | 3胡 | 6胡 |
| 二七十 | 3胡 | 6胡 |
| 普通顺子 | 0胡 | 0胡 |

- 跑、提后的胡息替换原牌型胡息，不叠加。
- 15～17胡：10元。
- 18～20胡：15元。
- 21～23胡：20元。
- 此后每增加3胡，加5元。
- 最终金额 = 胡息对应金额 × 总番数，两家分别支付。

## 3. 胡牌结构

- 无跑：7组三张牌组合。
- 有跑：6组牌 + 1对将。
- 可以通过跑牌后直接形成胡牌。

## 4. 吃牌

- 只能吃上家摸出或打出的牌。
- 合法吃法包括：普通顺子、一二三、二七十、大小搭。

### 下比

吃一张牌后，手中所有需要同时组成的相关牌必须全部下比；无法完成全部下比时，不能吃。

### 过张

一张牌曾经可以吃但没有吃，则以后不能再吃，但仍然可以胡。

## 5. 碰

- 碰不强制，可以选择不碰。
- 过碰后不能再碰。
- 过碰后如果自己从牌堆摸到第三张，则形成臭偎。
- 碰的优先级高于上家吃。

## 6. 坎、偎与臭偎

### 坎

- 起手三张相同为坎。
- 坎留在手牌中，不公开。

### 偎

- 手中已有两张相同牌，自己从牌堆摸到第三张时必须偎。
- 偎为强制动作。

### 臭偎

- 曾经过碰，之后自己摸到第三张相同牌，形成臭偎。
- 臭偎必须执行，并亮出其中一张牌。
- 胡息与普通偎相同。

偎、臭偎优先于胡牌。

## 7. 跑

### 碰后跑

已碰三张后，牌堆中任何人摸到第四张即形成跑；该牌仍然可以被其他玩家优先胡。

### 偎 / 坎后跑

已有偎牌或手中已有三张相同牌：

- 别人打出第四张：跑。
- 别人从牌堆摸出第四张：跑。
- 自己从牌堆摸出第四张：提。

### 跑与胡

- 胡优先于跑。
- 多人同时能胡时：摸牌者 > 下家 > 上家。

## 8. 提

以下情况形成提：

- 起手四张相同；
- 自己已有三张相同牌，再摸到第四张。

提为强制动作，提后必须亮出其中一张牌。

## 9. 夹比

- 第二次及以上发生跑或提时，本次进张后不需要再打牌。
- 起手已有两个提时，之后第一次发生进张，也不需要打牌。
- 进张包括：吃、碰、偎、跑、提。

## 10. 动作优先级

- 偎 / 提 > 胡。
- 胡 > 跑。
- 碰 > 上家吃。
- 胡牌内部：摸牌者 > 下家 > 上家。

## 11. 名堂

| 名堂 | 条件 | 番数 |
|---|---|---:|
| 黑胡 | 0张红牌 | 5番 |
| 点胡 | 1张红牌，其余全黑 | 4番 |
| 三扁 | 3张相同红牌，其余全黑 | 3番 |
| 四扁 | 4张相同红牌，其余全黑 | 4番 |
| 双漂 | 两组红牌碰/偎/跑/提，其余全黑 | 2番 |
| 十红 | 10张红牌 | 2番 |
| 十八大 | 18张大字 | 5番 |
| 十八小 | 18张小字 | 5番 |
| 碰碰胡 | 除有跑时允许的一对将外，其余均为碰/坎/偎/臭偎/跑/提 | 5番 |
| 天胡 | — | 5番 |
| 地胡 | — | 5番 |

- 十红：超过10张后，每多1张红牌，+1番。
- 十八大：超过18张后，每多1张大字，+1番。
- 十八小：超过18张后，每多1张小字，+1番。
- 碰碰胡不能有顺子、二七十或大小搭。

## 12. 名堂叠加

所有满足条件的名堂番数直接相加。

例如：黑胡 + 碰碰胡 + 十八大 = 5 + 5 + 5 = 15番。
