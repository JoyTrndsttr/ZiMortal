# 宁乡跑胡子规则

## 1. 基本规则

- 3人局，不属醒。
- 15胡起胡。
- 只有牌堆摸出的牌可以胡，别人打出的牌不能胡。
- 同一张牌多人可胡时，优先级：摸牌者 > 下家 > 上家。
- 达成胡牌条件后可以选择不胡，继续赌更大的胡息或名堂。
- 无海底。
- 一人胡牌后，另外两家分别支付相同金额，无放炮概念。
- “分锅”仅为玩家口头约定。

## 2. 胡息

| 牌型 | 小字 | 大字 |
|---|---:|---:|
| 碰 | 1胡 | 3胡 |
| 偎 / 坎 | 3胡 | 6胡 |
| 跑 | 6胡 | 9胡 |
| 提 | 9胡 | 12胡 |
| 一二三 | 3胡 | 6胡 |
| 二七十 | 3胡 | 6胡 |
| 普通顺子 | 0胡 | 0胡 |

- 跑、提后的胡息替换原牌型胡息，不叠加。
- 15～17胡：10元。
- 18～20胡：15元。
- 21～23胡：20元。
- 此后每增加3胡，加5元。
- 最终金额 = 胡息对应金额 × 总番数，两家分别支付。

## 3. 胡牌结构

- 无跑：7组三张牌组合。
- 有跑：6组牌 + 1对将。
- 可以通过跑牌后直接形成胡牌。
- 手中两张相同牌，胡别人摸出的第三张时，该三张组合按碰计胡息，不能按起手坎计分。
  仍可使用其他合法吃牌组合分解，不能强制把胡牌分解锁定为碰。

## 4. 吃牌

- 可以吃自己摸出的墩牌，也可以吃上家摸出或打出的牌；不能吃自己打出的牌。
- 碰优先于吃。碰的机会处理完毕后，墩牌的吃牌优先级为：摸牌者 > 下家。
- 摸牌者具备合法吃牌方案但选择不吃时，记录过张，再提供下家的吃牌机会。
- 合法吃法包括：普通顺子、一二三、二七十、大小搭。

### 下比

吃一张牌后，手中所有需要同时组成的相关牌必须全部下比；无法完成全部下比时，不能吃。
下比要求处理完来牌的同一字号牌型；大小搭中另一字号的同点牌不额外强制下比。
例如吃七七柒并下比二七十后，剩余一张柒可以留手。

### 过张

一张牌曾经可以吃但没有吃，或者自己曾主动打出，则以后不能再吃，但仍然可以胡。
自己打过的牌，无论后来自己摸出还是上家摸出／打出，都不能再吃。

## 5. 碰

- 碰不强制，可以选择不碰。
- 碰后若本次需要出牌却只剩不可拆的坎或空手，则该碰非法；夹比免出牌时例外。
- 过碰后不能再碰。
- 过碰后如果自己从牌堆摸到第三张，则形成臭偎。
- 碰的优先级高于上家吃。

## 6. 坎、偎与臭偎

### 坎

- 起手三张相同为坎。
- 坎留在手牌中，不公开。

### 偎

- 手中已有两张相同牌，自己从牌堆摸到第三张时必须偎。
- 偎为强制动作。

### 臭偎

- 曾经过碰，之后自己摸到第三张相同牌，形成臭偎。
- 臭偎必须执行，并亮出其中一张牌。
- 胡息与普通偎相同。

偎、臭偎优先于胡牌。

## 7. 跑

### 碰后跑

已碰三张后，牌堆中任何人摸到第四张即形成跑；该牌仍然可以被其他玩家优先胡。

### 偎 / 坎后跑

已有偎牌或手中已有三张相同牌：

- 别人打出第四张：跑。
- 别人从牌堆摸出第四张：跑。
- 自己从牌堆摸出第四张：提。

### 跑与胡

- 胡优先于跑。
- 多人同时能胡时：摸牌者 > 下家 > 上家。

## 8. 提

以下情况形成提：

- 起手四张相同；
- 自己已有三张相同牌，再摸到第四张。

提为强制动作，提后必须亮出其中一张牌。

## 9. 夹比

- 第二次及以上发生跑或提时，本次进张后不需要再打牌。
- 起手已有两个提时，之后第一次发生进张，也不需要打牌。
- 进张包括：吃、碰、偎、跑、提。

## 10. 动作优先级

- 偎 / 提 > 胡。
- 胡 > 跑。
- 碰 > 吃；墩牌吃牌内部：摸牌者 > 下家。
- 胡牌内部：摸牌者 > 下家 > 上家。

## 11. 名堂

| 名堂 | 条件 | 番数 |
|---|---|---:|
| 黑胡 | 0张红牌 | 5番 |
| 点胡 | 1张红牌，其余全黑 | 4番 |
| 三扁 | 3张相同红牌，其余全黑 | 3番 |
| 四扁 | 4张相同红牌，其余全黑 | 4番 |
| 双漂 | 两组红牌碰/偎/跑/提，其余全黑 | 2番 |
| 十红 | 10张红牌 | 2番 |
| 十八大 | 18张大字 | 5番 |
| 十八小 | 18张小字 | 5番 |
| 碰碰胡 | 除有跑时允许的一对将外，其余均为碰/坎/偎/臭偎/跑/提 | 5番 |
| 天胡 | — | 5番 |
| 地胡 | — | 5番 |

- 十红：超过10张后，每多1张红牌，+1番。
- 十八大：超过18张后，每多1张大字，+1番。
- 十八小：超过18张后，每多1张小字，+1番。
- 碰碰胡不能有顺子、二七十或大小搭。

## 12. 名堂叠加

所有满足条件的名堂番数直接相加。

例如：黑胡 + 碰碰胡 + 十八大 = 5 + 5 + 5 = 15番。

## 13. 第一版引擎开发时确认的口径

以下由维护者在开发会话中确认（2026-10-07）：

- 庄家起手21张，闲家各20张，牌堆19张；庄家打出第一张牌开始。
- 天胡：庄家起手满足胡牌条件。该条件是“只能胡墩牌”的开局例外。
- 地胡：闲家没有进张时，胡牌堆第一张牌。
- 没有名堂时为1番。
- “有跑：6组牌 + 1对将”包含提；多个跑/提时仍为6组牌加1对将。
- 下比按吃后剩余每张同牌均须参与完整下比处理；坎不可拆。
- 无人接的墩牌直接落桌，由下家摸牌。

## 14. 无牌可打的进张边界

维护者于2026-10-07进一步确认：

- 吃牌完成全部下比后，若本次仍须出牌却只剩不可拆的坎或空手，该吃牌非法。
  满足夹比免出牌条件时不受此限制。
- 偎／臭偎为强制动作，执行后不能胡且只剩坎或空手时，本次免出牌，由下家摸牌。
  该玩家本局不能胡，不再吃碰，后续摸牌按摸什么出什么处理。
- 上述状态不取消强制跑／提；这些动作仍须执行。

## 单钓结构补充说明（2026-10-08确认）

- 单钓仅适用于已有跑／提的“6组＋将”；无跑／提仍需7组。
- 六组已成、手中一张待配将时，进同牌成将仍须满足15胡息及实际来牌资格。
- 手牌可以有不同完整分解，不以理牌时的一种分组锁死听牌集合。
  例如带跑／提且其余组及胡息均符合条件时，一一壹＋贰可听贰、叁，
  一二三四五六七可听一、四、七；不得忽略其余组、牌数及胡息条件。
